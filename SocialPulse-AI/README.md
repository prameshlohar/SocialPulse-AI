# SocialPulse AI 🚀

> An intelligent AI-powered social media analytics platform for creators, influencers, and businesses.
> Built with **React** (CDN, no build step), **Python Flask**, and **IBM Granite via watsonx.ai**.

---

## ✨ Features

| Feature | Description |
|---|---|
| **Dashboard** | KPI cards, weekly engagement charts, platform performance, trending hashtags |
| **AI Strategy Agent** | Full social media strategy generated by IBM Granite |
| **AI Content Studio** | Captions, hooks, hashtags, CTAs with copy-to-clipboard |
| **Sentiment Analyzer** | Paste comments → Granite classifies positive/negative/neutral |
| **Trend Radar** | Trending topic cards with momentum scores and content angles |
| **Competitor Intelligence** | AI-analyzed competitor benchmarks and opportunities |
| **Audience Insights** | Age, geography, and interest breakdown charts |
| **Content Calendar** | Drag-and-drop weekly planner persisted in localStorage |

## ⚡ Quick Start (5 Minutes)

### 1. Backend Setup

```bash
cd backend

# Create virtual environment (recommended)
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate    # macOS/Linux

# Install dependencies
pip install -r requirements.txt

# Configure environment
copy .env.example .env
# Edit .env with your IBM credentials (or leave empty for Demo Mode)

# Start the Flask server
python app.py
```

The API will be available at **http://localhost:5000**

### 2. Frontend Setup

No build step required. Simply open in your browser:

```
frontend/index.html
```

**Or serve it with Python:**
```bash
cd frontend
python -m http.server 3000
# Open http://localhost:3000
```

> **Important:** The frontend makes API calls to `http://localhost:5000`. Make sure the Flask server is running.

## 🤖 IBM watsonx.ai Configuration

### Step 1: Create an IBM Cloud Account
1. Go to [https://cloud.ibm.com](https://cloud.ibm.com)
2. Sign up for a free account

### Step 2: Get Your API Key
1. Navigate to **Manage → Access (IAM) → API Keys**
2. Click **Create an IBM Cloud API key**
3. Copy and save the key

### Step 3: Set Up watsonx.ai Project
1. Go to [https://dataplatform.cloud.ibm.com](https://dataplatform.cloud.ibm.com)
2. Create a new **watsonx.ai project**
3. Copy the **Project ID** from Project settings

### Step 4: Configure Environment Variables

Edit `backend/.env`:
```env
WATSONX_API_KEY=your_actual_api_key
WATSONX_PROJECT_ID=your_actual_project_id
WATSONX_URL=https://us-south.ml.cloud.ibm.com
WATSONX_MODEL_ID=ibm/granite-13b-instruct-v2
```

### Available Regional URLs

## 🎨 Tech Stack

- **Frontend:** React 18 (CDN), Recharts 2, Tailwind CSS (CDN), Babel Standalone
- **Backend:** Python Flask 3, Flask-CORS, python-dotenv
- **AI:** IBM Granite 13B Instruct v2 via watsonx.ai
- **Storage:** Browser localStorage (Content Calendar)

---

## ⚠️ Important Notes

- **Sample Data:** All analytics, trends, and competitor metrics are **simulated** for demonstration. Not connected to live social media APIs.
- **Image Analysis:** The image upload feature captures a user-provided text description. IBM Granite is not performing image recognition — this is clearly indicated in the UI.
- **Credentials:** Never commit your `.env` file. It is listed in `.gitignore` by default.

## 🏆 Hackathon Notes

This project was built for rapid deployment. Key shortcuts taken:
- Frontend uses CDN React (no npm/build step) for maximum portability
- Backend uses only stdlib `urllib` for IBM API calls (no extra SDK dependency)
- All data is simulated — adding real API integrations is straightforward
